# Sarathi Journey

## From application status to a journey you can actually complete.

Sarathi Journey is a citizen-first UX prototype rethinking the driving-licence endorsement experience on Sarathi / Parivahan.

The prototype focuses on one specific scenario:

> An existing LMV Driving Licence holder wants to add MCWG (Motorcycle With Gear) to their existing licence.

---

## The Problem

Sarathi presents a complex government process through separate services, forms, transactions and technical application statuses.

But citizens experience the task as one continuous goal:

> "I want to add MCWG to my licence."

The challenge is not simply completing a form.

The challenge is understanding:

- what needs to happen before applying
- where the applicant currently is
- who needs to act
- whether the applicant needs to do anything
- what happens next
- what to do if progress stops

### Core insight

> The application has a status. The applicant needs a next step.

---

## The Proposed Solution

Sarathi Journey adds a citizen-facing journey layer around the existing government workflow.

It makes visible:

1. Prerequisites
2. Eligibility
3. Current stage
4. Responsibility
5. Next action
6. Waiting
7. State changes
8. Recovery
9. Completion

The underlying government process is not replaced.

The prototype reorganises how the citizen understands it.
