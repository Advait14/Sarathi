# 07 — Design System

## Design Direction

The product should feel:

- civic
- trustworthy
- modern
- calm
- accessible

It should feel like a significant improvement over a traditional government portal without looking like a consumer startup.

---

# Color Tokens

## Primary

Deep navy / indigo.

Use for:

- primary actions
- key headings
- navigation

## Accent

Civic blue.

Use for:

- active journey
- links
- progress

## Success

Green.

Use for:

- completed stages
- confirmations

## Warning

Amber.

Use for:

- waiting
- attention
- eligibility

## Error

Red.

Use for:

- blocked
- serious errors

## Information

Blue.

Use for:

- contextual information

## Background

Light neutral.

## Surface

White / light neutral.

---

# Typography

Use a modern sans-serif.

## Display

Large, high-impact headings.

## Heading

Section titles.

## Body

Readable paragraph copy.

## Label

Short metadata.

## Caption

Supporting information.

---

# Spacing

Use an 8px-based spacing system.

Suggested:

4
8
12
16
24
32
40
48
64
80

---

# Radius

Use restrained radius values.

Suggested:

8px
12px
16px

Avoid excessive rounded UI.

---

# Shadows

Use subtle shadows only where elevation is needed.

Avoid decorative shadows.

---

# Components

## Button

States:

- default
- hover
- focus
- disabled
- loading

---

## Journey Step

States:

- completed
- active
- upcoming
- blocked

---

## Status Card

Must communicate:

- status
- meaning
- responsibility
- action

---

## Action Card

Used when the user needs to act.

---

## Prerequisite Check

Used before entering the main process.

---

## Notification

Used for meaningful state changes.

---

## Recovery Panel

Used for blocked/stalled states.

---

# Accessibility

Minimum requirements:

- sufficient colour contrast
- visible keyboard focus
- semantic headings
- accessible buttons
- descriptive labels
- touch targets
- no colour-only state communication

---

# Visual Principles

## Hierarchy

Primary information should be obvious within seconds.

## Whitespace

Use whitespace to separate concepts.

## Simplicity

Prefer one strong message over multiple weak cards.

## Progress

Journey progress should be visually obvious.

## Responsibility

Differentiate citizen actions from system/RTO processing.

---

# Avoid

- glassmorphism
- gradients as decoration
- giant hero sections
- excessive illustrations
- dense dashboards
- excessive cards
- tiny typography
- excessive animation
- generic AI visual language
- copying current Sarathi UI
