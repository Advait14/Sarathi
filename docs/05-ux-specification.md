# Interaction Principles

- One primary CTA
- Explain before asking
- Never expose unexplained technical status
- Preserve journey context
- Use progressive disclosure
- Provide recovery
- Make waiting explicit

---

# Accessibility

- semantic HTML
- keyboard navigation
- visible focus
- sufficient contrast
- large touch targets
- labels for icons
- no state communicated through colour alone

---

# Mobile

Primary action should remain easy to reach.

Journey becomes vertical if necessary.

Important status copy should appear before secondary information.
