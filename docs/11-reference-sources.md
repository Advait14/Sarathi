# 6. Product Assumptions

The following are design assumptions unless independently verified:

- applicants benefit from a persistent journey
- explicit prerequisites reduce confusion
- actionable status reduces uncertainty
- proactive updates reduce repeated checking
- recovery guidance can reduce abandonment

These must be validated through research.

---

# 7. Synthetic Prototype Data

The following may be synthetic:

- application numbers
- dates
- appointment times
- notification timestamps
- application status
- user names
- journey transitions
- RTO responses

Synthetic data must never be presented as real government data.

---

# 8. Source Discipline

Before making a factual statement about the government process:

1. Check whether it is supported by the supplied evidence.
2. If not, verify through an appropriate authoritative source.
3. If it remains uncertain, label it as an assumption.
4. Never invent policy.

---

# 9. Research Principle

The prototype should be honest about what is:

- observed
- documented
- inferred
- hypothesised
- simulated
