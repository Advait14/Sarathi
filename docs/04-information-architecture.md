# 04 — Information Architecture

## Core Mental Model

The product is organised around the citizen's goal.

Not:

Services → Forms → Status

But:

Goal → Prerequisites → Journey → Next Action → Completion

---

# Primary Navigation

## Home / Goal

Purpose:

Start or resume a licence journey.

---

## Your Journey

Persistent view of the current endorsement process.

---

## Application Details

Secondary information.

Includes:

- application reference
- submission information
- service
- vehicle class
- relevant documents

---

## Notifications

Contextual updates related to the journey.

Not a generic notification centre.

---

## Help

Contextual help.

AI may assist here.
